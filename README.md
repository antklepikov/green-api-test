# GREEN-API Test

Простой чат WhatsApp на React, TypeScript и MUI. Приложение отправляет и получает текстовые сообщения через GREEN-API. Сборка — Webpack, серверная часть отсутствует.

## Требования

- Node.js 22 или новее и npm.
- Git для клонирования репозитория.
- Инстанс WhatsApp в GREEN-API с подключённым аккаунтом.
- Данные инстанса: `idInstance` и `apiTokenInstance`.

## Локальный запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/antklepikov/green-api-test.git
   cd green-api-test
   ```

2. Установите зависимости из `package-lock.json`:

   ```bash
   npm ci
   ```

3. Запустите сервер разработки:

   ```bash
   npm start
   ```

4. Откройте [http://localhost:3000](http://localhost:3000).

Остановить сервер можно сочетанием `Ctrl+C`. Команда `npm run dev` запускает тот же сервер.

Если порт 3000 занят, используйте другой:

```bash
npm start -- --port 3001
```

В этом случае приложение доступно по адресу [http://localhost:3001](http://localhost:3001).

## Подготовка GREEN-API

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com/) и создайте инстанс WhatsApp.
2. Подключите свой WhatsApp через QR-код в разделе связанных устройств мобильного приложения. Состояние инстанса должно быть `authorized`.
3. Скопируйте `idInstance` и `apiTokenInstance` из карточки инстанса.
4. Введите эти данные на странице входа нашего приложения.

При входе приложение проверяет авторизацию и настраивает получение уведомлений:

```json
{
  "webhookUrl": "",
  "incomingWebhook": "yes"
}
```

Пустой `webhookUrl` нужен для [получения уведомлений через HTTP API](https://green-api.com/docs/api/receiving/technology-http-api/): приложение само опрашивает GREEN-API методом `receiveNotification`.

Изменения настроек могут применяться до 5 минут. Если входящие сообщения не появляются, проверьте `incomingWebhook` через [GetSettings](https://green-api.com/docs/api/account/GetSettings/). Он должен иметь значение `yes`. Настройку также можно включить в кабинете: **Изменить → Получать уведомления о входящих сообщениях и файлах → Сохранить изменения**.

Переменные окружения и файл `.env` для запуска не нужны: каждый пользователь вводит свои credentials в интерфейсе.

## Проверка переписки

1. Введите номер собеседника с кодом страны, например `+7 999 123-45-67`, и нажмите **Создать чат**.
2. Напишите текст и нажмите круглую кнопку отправки.
3. Ответьте с WhatsApp собеседника новым текстовым сообщением.
4. Ответ появится в открытом чате.

Для проверки используйте одну открытую вкладку приложения с данным инстансом. Одновременный запуск локального и опубликованного приложения может привести к тому, что уведомление обработает другая вкладка.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm start` | Запуск локального сервера на порту 3000 |

| `npm run typecheck` | Проверка TypeScript |
| `npm run build` | Production-сборка в папку `dist` |

## Особенности

- Поддерживается один выбранный чат и обмен текстовыми сообщениями.
- Стикеры и другие нетекстовые сообщения выбранного чата отображаются текстовой пометкой.
- Уведомления об исходящих сообщениях и их статусах выбранного чата подтверждаются без добавления дублей.
- Событие другого чата останавливает получение и сохраняется в очереди GREEN-API.
- Credentials хранятся в `sessionStorage` текущей вкладки. Кнопка **Выйти / сменить инстанс** удаляет их.
- Переписка хранится в памяти приложения и сбрасывается при обновлении страницы, создании другого чата или выходе. История из WhatsApp не загружается.
